# Cuaderno 4.0.1

- **Actualizaciones con confirmación:** antes de descargar e instalar se pregunta si quieres actualizar. «Ahora no» y Escape permiten continuar trabajando.
- **Acceso directo a Aula Virtual:** nuevo botón junto a Intranet, con sesión compartida y credenciales locales cifradas. El acceso guardado permite renovar la sesión sin volver a escribir la contraseña. Si la UV rechaza el acceso o pide una verificación adicional, se detiene para que la completes.
- **Profesorado:** el contador distingue las fichas de la asignatura y el total. «Ver todas las fichas» permite abrir las de las demás asignaturas.
- **Tamaño de letra:** el selector indica el tamaño real, en puntos, del lugar donde está el cursor o del texto seleccionado. Muestra «Mixto» cuando la selección contiene varios tamaños y reconoce tamaños personalizados y heredados.

Incluye todas las mejoras de la versión 4.0.0. Los datos guardados se conservan al actualizar.

## Descargas

- **Mac con chip Apple:** Cuaderno-mac-arm64.dmg.
- **Mac Intel:** Cuaderno-mac-x64.dmg.
- **Windows de 64 bits:** Cuaderno-win-x64.exe.
